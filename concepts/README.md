# Five design concepts — 2026-09-18

Grounded in `~/arthur/knowledge/design/saas-landing-craft-study-2026-08.md`, which was
built from ~32 Dribbble SaaS shots and 18 Awwwards SOTD sites. Its governing rule:
five concepts that differ only in palette are one concept. These differ in what the
page is looking at.

| # | Concept | Central move | Reference register |
|---|---------|--------------|--------------------|
| 1 | Terminal | the capability board IS the hero; NOT CONNECTED shown on purpose | Vercel / Retool |
| 2 | Operator's Night | full-bleed photograph of service, UI panels floating over it | Orizon / Ramp |
| 3 | Ledger | serif + cream + metal; a dense numeric table as the hero | Phenomenon Studio |
| 4 | Split | floor and system side by side, the thesis as the mechanic | — |
| 5 | Proof Wall | type as composition; every figure carries its probe line | Linear / editorial |

Concepts 2 and 4 are BLOCKED on real Dabney photography. The gradients standing in for
photographs are placeholders and should not be judged as the design.
