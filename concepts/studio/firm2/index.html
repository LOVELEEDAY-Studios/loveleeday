Eight concepts, each one traceable.

Every layout below is taken from a named reference — five from Dribbble's architecture-firm work, three from live enterprise sites on Mobbin — and the reference is printed next to the concept so the argument for it can be checked rather than taken on trust. Type and colour are the site's real tokens, and every figure is read from the ontology at build time: 159 objects, 1,659 observations, 7 live sources.

4 of 5 frames not generated yet (colonnade, facade, stair, threshold) — those plates render as marked placeholders rather than borrowed stock, so what you are judging is the layout.
