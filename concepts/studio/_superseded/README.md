# Superseded

Four separate attempts at "the site" lived here at once — `site/`,
`solstice-site/`, `solstice-full/` and `concepts/` — each holding a different
subset of the decisions, and none holding all of them. That is what Daniel
meant on 2026-09-21 by "you never finished the true build": it was a
consolidation problem, not a design one.

`build-final.py` supersedes all of them and carries every decision. These are
kept only so the reasoning behind each step stays readable; nothing here is
built or served.
