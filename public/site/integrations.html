What to expect from a connection.

It reads and changes nothing

A connection reads what the system holds. If you ever want Arthur to write something back, it asks for your approval first.

It is set up for your account

We set up each connection for your organization and check the records it returns before you rely on them.

An export can stand in for it

If your system can export its data, we can often start there. We will tell you what we can read and explain any limits.
