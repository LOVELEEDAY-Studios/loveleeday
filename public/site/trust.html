Controls overview

Six controls we can describe in a sentence.

Approval before anything goes out

A send, a write to a source system, a deployment: outbound actions pass an approval and logging step instead of running unsupervised.

Your data, your tenant

Each client is isolated in the database itself with row-level security, on a dedicated client-data project, not only in application code.

Sign-in you can rely on

Multi-factor authentication through an authenticator app is required for account access. Client accounts are created by invitation, never self-registered.

A record of what happened

Sends, writes, deployments and access changes are logged and reviewable after the fact.

United States hosting, encrypted

Compute runs in Chicago and databases in AWS us-east-1. Traffic uses TLS and data is encrypted at rest.

Deletion with a certificate

On termination or written request, client data is deleted from production within 30 days, with a signed deletion certificate.

Disclosed plainly

What is not finished.

One operator

LOVELEEDAY Studios LLC is a single-operator company. There is no second engineer on call; automated monitoring and a written incident plan carry the load.

Backup responder

An external incident-response retainer is being engaged as the named backup. It is not yet under contract.

Independent testing

An independent penetration test is scoped but not yet performed. Our own security review is not a substitute for it.
