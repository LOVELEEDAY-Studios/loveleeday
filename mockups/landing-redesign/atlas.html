■ FIG.02  /  Guarantees

Enforced, not promised.

Five properties the system holds by construction. Each one blocks a specific way a business answer goes quietly wrong.

01

Identity resolution

A payments customer, a vendor id in the ledger and a string in an email signature are three records and one company. You ask about the object, never about whichever string a source happened to use.

✓ Enforced
02

Bitemporality

Every property knows when it was valid in the world and when it was observed. Judging an August decision with September knowledge is look-ahead bias; the two timelines are kept apart so it can't happen quietly.

✓ Enforced
03

Lineage

Writing a value requires its source system and source reference. The trail prints for any figure. A number with no trail is not reportable.

✓ Enforced
04

Bounded autonomy

Actions are classified by blast radius. Only the reversible class runs unattended; anything touching money, outbound communication or a legal document waits for a person.

✓ Enforced
05

Observed completion

Work closes on a value read back out of the system that was supposed to change. An HTTP 200 is not evidence anything happened.

✓ Enforced
